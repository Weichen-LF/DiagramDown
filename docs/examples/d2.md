# D2 preview smoke test

This document exercises DiagramDown's local D2 CLI integration. Each section
covers a common D2 modeling style.

## Service flow

```d2
direction: right

client: Client {
  shape: person
}

api: API
database: Database {
  shape: cylinder
}

client -> api: request
api -> database: query
database -> api: result
api -> client: response
```

## Sequence diagram

```d2
shape: sequence_diagram

User -> DiagramDown: Edit Markdown
DiagramDown -> D2: Render locally
D2 -> DiagramDown: SVG
DiagramDown -> User: Updated preview
```

## SQL tables

```d2
users: {
  shape: sql_table
  id: int {constraint: primary_key}
  email: string {constraint: unique}
  name: string
}

documents: {
  shape: sql_table
  id: int {constraint: primary_key}
  user_id: int {constraint: foreign_key}
  path: string
  body: text
}

diagrams: {
  shape: sql_table
  id: int {constraint: primary_key}
  document_id: int {constraint: foreign_key}
  kind: string
  source: text
}

users.id -> documents.user_id
documents.id -> diagrams.document_id
```

```d2
direction: right

  shape: cloud

}

  label: Edge

  }

  label: Application

  worker: Worker
}

  label: Data

  }

    shape: cylinder
  }

internet -> edge.cdn -> edge.lb

app.api -> data.postgres
app.worker -> data.redis
```

## State-style flow

```d2
direction: right

Idle -> Rendering: source changed
Rendering -> Ready: success
Rendering -> Failed: error
Failed -> Rendering: retry
Ready -> Rendering: source changed
Ready -> Idle: close
```

## Styled connections

```d2
direction: down

source: Markdown source
ast: Preview AST
diagram: Diagram CLI
svg: Sanitized SVG

source -> ast: parse {
  style.stroke-dash: 3
}
ast -> diagram: fence source {
  style.stroke: "#0D32B2"
}
diagram -> svg: render {
  style.animated: true
}
svg -> ast: embed {
  style.stroke: "#2E7D32"
}
```
