# DiagramDown 0.26.0

## Highlights

DiagramDown 0.26.0 keeps the workspace tree in sync with the filesystem, makes
the active editor line easier to spot, and adds optional Mermaid rendering with
[`mmdr`](https://github.com/1jehuang/mermaid-rs-renderer).

## Requirements

- macOS 15 or later
- Apple Silicon
- Mermaid diagrams optionally require either
  `npm install -g @mermaid-js/mermaid-cli` or
  `brew tap 1jehuang/mmdr && brew install mmdr`
- D2 diagrams optionally require `brew install d2`

## Changes

- Auto-refresh the sidebar directory tree when files or folders appear,
  disappear, or change outside DiagramDown (every 10 seconds, and when a tree
  row is clicked)
- Highlight the active editor line with a subtle row background
- Settings > Mermaid Preview can choose `mmdc` (PNG preview) or `mmdr`
  (sanitized SVG preview)
- Diagram Tools status covers `mmdc`, `mmdr`, and `d2`
- Sidebar auto-refresh avoids publishing when nothing changed, so nested Edit
  menus stay usable

## Verify the release

```sh
shasum -a 256 -c DiagramDown-0.26.0-arm64.dmg.sha256
hdiutil verify DiagramDown-0.26.0-arm64.dmg
```

The command must report `DiagramDown-0.26.0-arm64.dmg: OK`.
