# DiagramDown 0.20.0

> [!IMPORTANT]
> This Apple Silicon build is ad-hoc signed and is not notarized by Apple. macOS Gatekeeper may block the first launch. Verify the checksum and repository source, then use Finder's **Open** command or **Open Anyway** in System Settings > Privacy & Security. Never disable Gatekeeper globally.

DiagramDown 0.20.0 makes exported PDFs reliable and adds an offline formatting and code-highlighting workflow.

## Requirements

- macOS 15.0 or later
- Apple Silicon Mac
- Intel Macs are not supported by this release

## Highlights

- Export the complete rendered Markdown preview to a validated, paginated PDF
- Avoid the previous WebKit printing path that could produce blank files or trigger an AppKit debug assertion
- Format a document with **Edit > Format Document** or **Shift-Option-F**
- Format Markdown and supported embedded JSON, JavaScript, TypeScript, HTML, CSS, and YAML with bundled Prettier
- Format D2 fenced blocks with the official bundled `d2 fmt` command
- Preserve Mermaid fenced-block source without applying an experimental formatter
- Highlight explicitly labeled code fences in the preview using bundled Highlight.js
- Keep all formatting and highlighting dependencies inside the application bundle with no CDN or network access

## Download verification

Download the ZIP and `.sha256` file into the same directory, then run:

```sh
shasum -a 256 -c DiagramDown-0.20.0-arm64.zip.sha256
```

The command must report `DiagramDown-0.20.0-arm64.zip: OK`.

## First launch

After verifying the download, unzip it and Control-click or right-click `DiagramDown.app`, then choose **Open**. If macOS still blocks it, use **Open Anyway** in System Settings > Privacy & Security.

## Known limitations

- The release is not Apple-notarized.
- Only Apple Silicon is supported; the bundled D2 helper is arm64-only.
- Mermaid source formatting is intentionally deferred.
- Unknown fenced-code languages remain unchanged and are displayed as escaped plain text.
- Automatic updates are not included. Download later releases from this repository.
