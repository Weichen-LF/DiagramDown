# DiagramDown 0.21.0

> [!IMPORTANT]
> This Apple Silicon build is ad-hoc signed and is not notarized by Apple. macOS Gatekeeper may block the first launch. Verify the checksum and repository source, then use Finder's **Open** command or **Open Anyway** in System Settings > Privacy & Security. Never disable Gatekeeper globally.

DiagramDown 0.21.0 adds folder workspaces and safe multi-file Markdown editing while preserving the existing single-file document workflow.

## Requirements

- macOS 15.0 or later
- Apple Silicon Mac
- Intel Macs are not supported by this release

## Highlights

- Open a folder with **File > Open Folder…** or **Shift-Command-O**
- Browse a lazily loaded directory tree without recursively scanning the workspace
- Open multiple `.md` and `.markdown` files as tabs in one workspace window
- Keep independent text, Undo, selection, scroll, preview, layout, and dirty state for each file
- Save the active workspace file atomically with **Command-S**
- See dirty indicators and saving progress directly in the tab bar
- Choose Save, Discard, or Cancel when closing a modified tab
- Choose Save All, Discard Changes, or Cancel when closing a workspace with modified files
- Continue using the existing single-file Finder, Open, Save As, and autosave workflow

## Safety and sandboxing

- Folder access is granted only through the system open panel and retained with a security-scoped bookmark
- Directory children are loaded one level at a time away from the main actor
- Symbolic links are not followed from the workspace tree
- Workspace reads and writes verify that files remain inside the selected root
- Workspace editing is limited to regular UTF-8 Markdown files no larger than 4 MB
- Non-Markdown files remain visible in the tree but cannot be opened by this release

## Download verification

Download the ZIP and `.sha256` file into the same directory, then run:

```sh
shasum -a 256 -c DiagramDown-0.21.0-arm64.zip.sha256
```

The command must report `DiagramDown-0.21.0-arm64.zip: OK`.

## First launch

After verifying the download, unzip it and Control-click or right-click `DiagramDown.app`, then choose **Open**. If macOS still blocks it, use **Open Anyway** in System Settings > Privacy & Security.

## Known limitations

- The release is not Apple-notarized.
- Only Apple Silicon is supported; the bundled D2 helper is arm64-only.
- Workspace files use explicit saving; workspace autosave is not enabled.
- Workspace tabs and expansion state are not yet restored after relaunch.
- External file changes and conflicts are not yet detected automatically.
- Creating, renaming, moving, or deleting files from the sidebar is not yet supported.
- Quick Open, workspace search, split editor groups, and Git decorations are deferred.
- Automatic updates are not included. Download later releases from this repository.
