# DiagramDown 0.22.0

> [!IMPORTANT]
> This Apple Silicon build is ad-hoc signed and is not notarized by Apple. macOS Gatekeeper may block the first launch. Verify the checksum and repository source, then use Finder's **Open** command or **Open Anyway** in System Settings > Privacy & Security. Never disable Gatekeeper globally.

DiagramDown 0.22.0 makes folder workspaces the sole application mode, restores in-progress work after relaunch, and moves community releases to a drag-to-Applications DMG.

## Requirements

- macOS 15.0 or later
- Apple Silicon Mac
- Intel Macs are not supported by this release

## Highlights

- Launch directly into the most recently used folder workspace
- Show a DiagramDown **Open Folder…** welcome screen when there is no previous workspace
- Use **File > Open Folder…** or **Command-O** to replace the current workspace
- Restore open tabs, the active file, sidebar and expanded-directory state, per-tab layout, and editor scroll position
- Recover unsaved edits and newly created unsaved buffers after an application restart or crash
- Reload clean tabs from disk while preserving recovery copies for dirty tabs
- Save recovery snapshots atomically inside the application sandbox
- Remove the separate single-file document browser, document window lifecycle, and Finder Markdown associations
- Install from a DMG containing `DiagramDown.app` and an Applications shortcut

## Download verification

Download the DMG and `.sha256` file into the same directory, then run:

```sh
shasum -a 256 -c DiagramDown-0.22.0-arm64.dmg.sha256
```

The command must report `DiagramDown-0.22.0-arm64.dmg: OK`.

## First launch

After verifying the download, open the DMG and drag `DiagramDown.app` to the Applications shortcut. Control-click or right-click the installed application and choose **Open**. If macOS still blocks it, use **Open Anyway** in System Settings > Privacy & Security.

## Known limitations

- The release is not Apple-notarized.
- Only Apple Silicon is supported; the bundled D2 helper is arm64-only.
- Workspace files use explicit saving; automatic file saving is not enabled.
- External file changes and conflicts are not yet detected automatically.
- Creating, renaming, moving, or deleting files from the sidebar is not yet supported.
- Quick Open, workspace search, split editor groups, and Git decorations are deferred.
- Finder does not advertise DiagramDown as a standalone Markdown file handler; open the containing folder instead.
- Automatic updates are not included. Download later releases from this repository.
