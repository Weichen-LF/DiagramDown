# DiagramDown 0.19.0

> [!IMPORTANT]
> This Apple Silicon build is ad-hoc signed and is not notarized by Apple. macOS Gatekeeper may block the first launch. Verify the checksum and repository source, then use Finder's **Open** command or **Open Anyway** in System Settings > Privacy & Security. Never disable Gatekeeper globally.

DiagramDown 0.19.0 makes the editor easier to discover and adds a privacy-preserving diagnostics report for support requests. It combines the planned 0.18 onboarding work and 0.19 diagnostics work into one release.

## Requirements

- macOS 15.0 or later
- Apple Silicon Mac
- Intel Macs are not supported by this release

## Highlights

- Open an editable, bundled Markdown example from the Help menu
- Explore Markdown, Mermaid, D2, focused diagram viewing, and export in one document
- See lightweight guidance when a new document is empty
- Review common keyboard shortcuts without leaving DiagramDown
- Export a plain-text diagnostics report from the Help menu
- Include useful application, macOS, architecture, preview setting, D2 helper, and cache information in issue reports
- Keep document content, document names, file paths, cache filenames, and personal identifiers out of diagnostics
- Open the project page, issue form, and latest release notes directly from Help

## Download verification

Download the ZIP and `.sha256` file into the same directory, then run:

```sh
shasum -a 256 -c DiagramDown-0.19.0-arm64.zip.sha256
```

The command must report `DiagramDown-0.19.0-arm64.zip: OK`.

## First launch

After verifying the download, unzip it and Control-click or right-click `DiagramDown.app`, then choose **Open**. If macOS still blocks it, use **Open Anyway** in System Settings > Privacy & Security.

After launch, choose **Help > Open Example Document** for a quick tour. The example opens as a new editable document; save it only if you want to keep your changes.

If you need to report a problem, choose **Help > Export Diagnostics…**, inspect the plain-text report, and attach it to the issue. The report is deliberately limited to non-document support information.

## Known limitations

- The release is not Apple-notarized.
- Only Apple Silicon is supported; the bundled D2 helper is arm64-only.
- Automatic updates are not included. Download later releases from this repository.
- D2 diagrams cannot reference arbitrary external local resources.
