# DiagramDown 0.17.0

> [!IMPORTANT]
> This Apple Silicon build is ad-hoc signed and is not notarized by Apple. macOS Gatekeeper may block the first launch. Verify the checksum and repository source, then use Finder's **Open** command or **Open Anyway** in System Settings > Privacy & Security. Never disable Gatekeeper globally.

DiagramDown 0.17.0 is the first public community release of the native macOS Markdown and diagram editor.

## Requirements

- macOS 15.0 or later
- Apple Silicon Mac
- Intel Macs are not supported by this release

## Highlights

- Native Markdown editing with line numbers, find, undo, and automatic document saving
- Offline Markdown preview with light and dark appearance support
- Offline Mermaid and sandboxed D2 fenced-block rendering
- Smooth bidirectional editor-preview scroll synchronization
- Editor-only, split, and preview-only window layouts
- Markdown preview and focused diagram zoom, including trackpad pinch gestures
- Mermaid and D2 SVG export
- Full-document Markdown preview PDF export
- Persistent themes, diagram settings, zoom, and disk cache

## Download verification

Download the ZIP and `.sha256` file into the same directory, then run:

```sh
shasum -a 256 -c DiagramDown-0.17.0-arm64.zip.sha256
```

The command must report `DiagramDown-0.17.0-arm64.zip: OK`.

## First launch

After verifying the download, unzip it and Control-click or right-click `DiagramDown.app`, then choose **Open**. If macOS still blocks it, use **Open Anyway** in System Settings > Privacy & Security.

## Known limitations

- The release is not Apple-notarized.
- Only Apple Silicon is supported; the bundled D2 helper is arm64-only.
- Automatic updates are not included. Download later releases from this repository.
- D2 diagrams cannot reference arbitrary external local resources.
