# DiagramDown 0.23.0

> [!IMPORTANT]
> This Apple Silicon build is ad-hoc signed and is not notarized by Apple. macOS Gatekeeper may block the first launch. Verify the checksum and repository source, then use Finder's **Open** command or **Open Anyway** in System Settings > Privacy & Security. Never disable Gatekeeper globally.

DiagramDown 0.23.0 replaces the browser-backed Markdown preview with a native
SwiftUI pipeline and moves Mermaid and D2 rendering to optional command-line
tools installed by the user.

## Requirements

- macOS 15.0 or later
- Apple Silicon Mac
- Mermaid diagrams optionally require
  `npm install -g @mermaid-js/mermaid-cli`
- D2 diagrams optionally require `brew install d2`

## Highlights

- Render Markdown with `swift-markdown` and native SwiftUI views without
  WKWebView, WebKit, JavaScriptCore, or bundled browser runtimes
- Highlight supported fenced-code languages with bundled Tree-sitter grammars
- Discover local `mmdc` and `d2` executables automatically or through a custom
  path selected in Settings
- Fall back to the original fenced source when a diagram tool is unavailable,
  and show a bounded diagnostic when an installed tool cannot render
- Render sanitized SVG output with the native macOS SVG image representation
- Preserve diagram themes, D2 layout settings, SVG export, and native paginated
  PDF export
- Format Markdown with `swift-markdown`, preserving non-D2 fenced source
- Bound syntax-highlight and diagram caches and purge them under memory pressure
- Remove the bundled Mermaid runtime, D2 helper, Prettier, SVGView, App Sandbox,
  and obsolete WebKit resources and entitlements
- Improve stable-block reconciliation for documents containing thousands of
  repeated structural blocks

## Download verification

Download the DMG and `.sha256` file into the same directory, then run:

```sh
shasum -a 256 -c DiagramDown-0.23.0-arm64.dmg.sha256
```

The command must report `DiagramDown-0.23.0-arm64.dmg: OK`.

## First launch

After verifying the download, open the DMG and drag `DiagramDown.app` to the
Applications shortcut. Control-click or right-click the installed application
and choose **Open**. If macOS still blocks it, use **Open Anyway** in System
Settings > Privacy & Security.

## Known limitations

- The release is not Apple-notarized.
- Only Apple Silicon is supported.
- Mermaid and D2 rendering depends on optional, separately installed CLI tools;
  DiagramDown does not install or update them.
- Tree-sitter highlighting currently covers Swift, Lua, JavaScript/JSX,
  TypeScript/TSX, JSON, YAML, and Bash. Other languages safely use plain text.
- Workspace files use explicit saving; automatic file saving is not enabled.
- External file changes and conflicts are not yet detected automatically.
- Creating, renaming, moving, or deleting files from the sidebar is not yet
  supported.
- Quick Open, workspace search, split editor groups, Git decorations, and
  automatic updates are not included.
- Finder does not advertise DiagramDown as a standalone Markdown file handler;
  open the containing folder instead.
