# DiagramDown 0.24.0

> [!IMPORTANT]
> This Apple Silicon build is ad-hoc signed and is not notarized by Apple. macOS Gatekeeper may block the first launch. Verify the checksum and repository source, then use Finder's **Open** command or **Open Anyway** in System Settings > Privacy & Security. Never disable Gatekeeper globally.

DiagramDown 0.24.0 makes folder workspaces safer and more complete while
improving local Mermaid rendering, images, syntax highlighting, and Markdown
editing.

## Requirements

- macOS 15.0 or later
- Apple Silicon Mac
- Mermaid diagrams optionally require
  `npm install -g @mermaid-js/mermaid-cli`
- D2 diagrams optionally require `brew install d2`

## Highlights

- Detect files changed or deleted outside DiagramDown, automatically refresh
  clean buffers, and require an explicit reload or overwrite for conflicts
- Create Markdown files and folders, rename or move workspace items, and delete
  them from the sidebar
- Restore the window frame and sidebar width alongside tabs, scroll positions,
  layouts, and unsaved edits
- Reopen folders from **File > Open Recent** and close the current file with
  Command-W
- Insert common Markdown constructs from the Edit menu, including emphasis,
  links, headings, lists, code blocks, tables, and horizontal rules
- Add Tree-sitter highlighting for Dockerfile, Python, SQL, Go, and Lua
- Preview common local image formats from relative, absolute, and `file://`
  paths
- Preserve Mermaid's default HTML labels by displaying PNG preview output while
  retaining the original CLI-generated SVG for export
- Clear all syntax and diagram caches from Settings

## Download verification

Download the DMG and `.sha256` file into the same directory, then run:

```sh
shasum -a 256 -c DiagramDown-0.24.0-arm64.dmg.sha256
```

The command must report `DiagramDown-0.24.0-arm64.dmg: OK`.

## First launch

After verifying the download, open the DMG and drag `DiagramDown.app` to the
Applications shortcut. Control-click or right-click the installed application
and choose **Open**. If macOS still blocks it, use **Open Anyway** in System
Settings > Privacy & Security.

## Known limitations

- The release is not Apple-notarized.
- Only Apple Silicon is supported.
- Mermaid and D2 rendering depends on optional, separately installed CLI tools;
  DiagramDown does not install or update them.
- Workspace files use explicit saving; automatic file saving is not enabled.
- Quick Open, workspace search, split editor groups, Git decorations, and
  automatic updates are not included.
- Finder does not advertise DiagramDown as a standalone Markdown file handler;
  open the containing folder instead.
